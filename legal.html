隐私说明

栖心是一个静态网页。它没有项目作者运营的后端服务器、用户账号系统、统计工具或广告。这份说明解释页面在你的浏览器里保存什么、什么时候会把内容发送给 DeepSeek，以及你可以如何删除数据。

这是一份面向使用者的说明，不构成法律意见。若你准备在特定地区公开运营，请根据当地法律和平台要求做进一步审查。

1. 你的内容保存在哪里

你写下的练习记录、每一幕的收束句、本次主线摘要和页面设置，保存在当前浏览器的 localStorage 中。相关键名包括：

  • qixin.therapist.v1.state：七幕练习记录与主线，未加密
  • qixin.therapist.v1.consent：是否完成首次确认，不含练习内容
  • qixin.therapist.v1.key：API Key，仅当前会话
  • qixin.therapist.v1.key.remember：API Key，仅在主动勾选“记住”后写入

这些数据不会发送到项目作者的服务器。但 localStorage 没有加密，同一浏览器中的扩展、恶意脚本或其他能访问该页面的人，理论上可以读取。公共电脑、共享设备或他人可访问的浏览器不适合保存私密记录。

清理浏览器站点数据、使用无痕模式或更换浏览器/域名，会导致记录不可用或丢失。

2. 什么时候会发送给 DeepSeek

只有当你主动填写自己的 DeepSeek API Key，并在设置中连接成功后，AI 功能才会启用。启用后，以下内容会发送到 https://api.deepseek.com/chat/completions：

  • 你刚完成的那一层记录（事件、情绪、身体感受、需要、哀悼内容等）
  • 本次主线中已经收束的摘要
  • 当前幕与当前层的名称
  • 用于“润色”的收束文本

这些内容用于生成一段简短的注脚或润色结果。页面不会把整个浏览器的历史、其他网站的数据或你的 API Key 发送给项目作者。DeepSeek 如何保存和处理这些内容，取决于 DeepSeek 自己的服务条款与隐私政策。

如果不连接 API，页面只使用本地注脚，不会向 DeepSeek 发送内容。

3. API Key

  • 项目不包含任何内置 API Key
  • Key 只保存在你的浏览器中；默认使用 sessionStorage
  • 只有勾选“在这台设备记住 Key”时，才会写入 localStorage
  • 导出 JSON 时会排除 API Key
  • 接口固定为 DeepSeek 官方地址，不提供自定义网关

请不要在公共电脑上勾选“记住 Key”，也不要把自己的 Key 交给他人或公共代理。

4. 我们不做的事

  • 不收集姓名、手机号、邮箱或账号
  • 不设置统计脚本、广告像素或第三方分析
  • 不把内容出售给第三方
  • 不把内容上传到项目作者自己的服务器
  • 不建立用户画像

5. 删除你的数据

可以在页面“设置与数据”中导出 JSON、导出 Markdown、重新开始本次记录。若需彻底删除：清空记录 → 清除该站点的浏览器数据（localStorage / sessionStorage）→ 到 DeepSeek 控制台管理或撤销对应 Key。

6. 未成年人

本页面面向成年人。未成年人不建议单独使用；如确有需要，应在监护人、咨询师或其他可信成年人的陪同下使用。

7. 变更与联系

如果这份说明发生重要变化，会在项目仓库中更新，并注明新的生效日期。如需反馈隐私问题，请在项目仓库中提交 issue；请不要在公开 issue 中粘贴 API Key、真实姓名或其他敏感信息。

免责声明与使用边界

1. 不是心理治疗

栖心是一个自我探索与情绪书写工具。它不是心理治疗、心理咨询、精神科诊疗、医疗设备或临床评估工具，也不构成任何形式的诊断、处方或专业建议。页面中的问题、注脚、案例和文字，只用于帮助使用者整理自己的感受与叙事，不能替代受过训练的专业人员对你具体处境的理解。

2. AI 会犯错

连接 DeepSeek 后，页面会使用 AI 生成简短的注脚或润色文字。AI 可能误读你的意思、给出不准确或不适合你的表述、遗漏重要背景，或生成看似专业但没有依据的判断。请不要把 AI 的输出当作事实、诊断或行动指令。

3. 不适合危机情况

栖心不是危机干预服务。如果你有伤害自己或他人的念头、有具体的自杀计划或准备行为，或正处于暴力、性侵、虐待、人身危险中，请优先联系现实中的支持：一个可信任的人、一个安全且有人的地方，或以下资源。

4. 哀悼与创伤内容

“溯源”“哀悼”两幕可能触及童年经历、失去、创伤和强烈情绪。你可以随时停下，不需要一次写完，也不需要在这里完成“原谅”或“放下”。如果某一部分让你感到明显失控、解离、持续失眠或无法日常运转，请寻求专业帮助。

5. 案例是虚构的

页面中的“林岚（化名）”案例是虚构的教学性材料，用于展示一条可能的心理线索。它不是真实来访者，不对应任何具体个人，也不构成诊断示例。

6. 不做保证

本项目按“现状”提供，不保证页面永不中断、AI 输出准确完整、适合某一特定诊断/年龄/文化/危机程度，或使用后一定产生某种情绪或关系改善。

7. 你的责任

使用本页面即表示你理解：你需要为自己的选择、行动和 API 费用负责；你不应把页面内容作为医疗、法律、财务或其他专业建议；你不应在公共设备上保存高度私密的内容；你应遵守所在地区的法律和 DeepSeek 的服务条款。
